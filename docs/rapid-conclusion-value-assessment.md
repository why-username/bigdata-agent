# Agent 对真实安全缺陷判断的快速价值评估

## 设置

对 EA22002、PE20016、PE23015、PE24004 四案，将官方结案摘要和最终召回结果留出，运行截点设在结案前一天。Agent 只能使用截点前投诉和公开材料。留出答案记录了后续确认的缺陷方向、机制和召回编号。

## 结果

四案均进入 `needs_human_review`，没有在证据不足时直接声称已经确认安全缺陷。Agent 分别识别了：EA22002 的驾驶员监督/控制缺口候选、PE20016 的电池热事件和召回信号、PE23015 的发动机润滑候选、PE24004 的倒车影像/线束候选，但都保留了替代解释和人工核验要求。

- 后续机制精确命中：0/4。截点前材料不足以要求模型准确复述结案后的最终机制。
- 安全校准：4/4。没有把投诉数量当故障率，也没有把候选机制写成已证实事实。
- 识别后续处置线索：3/4 有截点前召回或调查信号；PE24004 在截点前的运行证据不足，正确地保持待核验。
- 引用和截点检查：4/4 通过。

## 对核心价值的判断

当前实验不能证明 Agent 能在结案前准确判断“车辆已经存在真实安全缺陷”。它证明了另一个更符合公开资料条件的价值：Agent 能把调查分成候选缺陷线索、替代解释、证据缺口和人工核验条件，并避免在证据不足时做出过度结论。

这对应企业调查中的早期筛查和升级决策，而不是最终法律/工程缺陷认定。要测最终结论能力，必须增加“结案后反馈再运行”任务：先用截点前材料输出 provisional assessment，再揭示 holdout 结论，检查 Agent 是否能根据新证据更新假设、承认原判断的不确定性并形成可追溯的最终报告。
