# V3 候选案例筛选记录

候选来源为本地 NHTSA FLAT_INV 快照、投诉 API 快照和公开调查/召回材料。筛选条件：至少两类截点前独立公开材料、可关联投诉、可留出后续结论、能构造支持与反证任务。

| 优先级 | 案例 | 适合动态测试的原因 | 当前状态 |
|---|---|---|---|
| 1 | EA22002 Tesla Model 3 Autopilot | 调查升级、驾驶辅助软件与驾驶员控制存在竞争解释，适合反证和来源冲突 | 候选，需补齐截点包 |
| 2 | PE20016 Chevrolet Bolt EV 电池起火 | 电池缺陷、热事件、召回处置和外部因素可形成多假设 | 候选，需补齐截点包 |
| 3 | PE23015 Ford EcoSport 油泵失效 | 发动机失效、油压和维修/使用条件可拆分验证 | 候选，需补齐截点包 |
| 4 | RQ23004 Mustang Mach-E 接触器 | 高压电池接触器、失去动力和召回整改效果可做时间分段 | 候选，需补齐截点包 |
| 5 | PE24004 Honda Ridgeline 后视摄像头 | 部件明确，投诉和图像/软件/线束替代解释较清晰 | 候选，需补齐截点包 |

EA23003 继续作为主案，因为它已有完整本地快照、1949 条投诉、528 条截点前部件记录和留出结案材料。替换主案需要通过同一质量门槛，不能仅凭投诉量更大替换。
