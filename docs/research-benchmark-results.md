# 研究级基准首轮结果

本轮将研究数据扩展为 264 条冻结任务：1 个主案和 10 个公开迁移案例，每个案例取三个不晚于公开回放截点的历史截点，再对八个调查目标各生成一条任务。所有策略读取同一份本地快照，并使用同一个截点过滤器。

运行方式：

```bash
python scripts/build_research_benchmark.py
python pipeline.py eval --suite research --mode active_eig
```

结果文件为 `outputs/evaluations/eval-research-20261101-000348.json`、同名 CSV 和 Markdown。264/264 任务完成，0 条数据阻塞，0 条失败；31 条单元测试也全部通过。每一条主动 Agent 调查都生成了状态快照、运行轨迹和截点安全证据图。

自动分数只检查可审计行为：计划动作、证据来源、反证动作、补查动作和有界停止，每项 0 或 1 分，共 5 分。首轮结果如下：

| 策略 | 平均分 | 95% bootstrap 区间 | 平均耗时（ms） |
| --- | ---: | ---: | ---: |
| 固定流程 | 2.4583 | 2.3902–2.5303 | 约 68 |
| 普通 RAG | 1.4583 | 1.3902–1.5303 | 约 0 |
| ReAct | 2.5833 | 2.5152–2.6591 | 约 101 |
| 主动信息增益 Agent | 2.5833 | 2.5152–2.6591 | 约 74 |

这个结果证明了实验基础设施、截点隔离、工具调用边界和可追溯日志能够在三类案例上稳定运行。主动策略在本轮规则化基线中与 ReAct 的行为分数相同，不能据此宣称已经提高了语义调查质量；下一轮应使用真实模型、独立反证材料和更强的任务金标准，检验证据覆盖、竞争性假设区分率和引用质量是否出现差异。平均耗时仅表示本地工具循环，不包含 Qwen API 延迟。

证据图的节点包括案例、投诉、车型、部件和公开材料；边带有来源、日期和匹配依据。词法候选边明确标为候选关系，不被解释为共同根因。图文件保存在 `outputs/graphs/`，可由 Streamlit 页面查看。

研究结果仍受三项限制约束：扩展迁移案例是公开投诉快照和 ODI 结案摘要的精简回放包，不能替代完整 ODI 结案调查；自动分数不等同于缺陷判定正确率；Qwen API 的完整扩展套件尚未运行，需在共享服务器负载允许时按并发 1 选择代表任务执行。
