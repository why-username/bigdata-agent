# V4 最终结果对照指标修订

## 为什么安全通过率不能作为正确率

`final_safety_pass` 只检查截点、来源和停止边界。四种方法都得到 100% 说明系统没有越界，不说明调查决策正确。它保留为安全约束指标，不能作为主要效果指标。

## 最终结果正确率

V4 为每个动态场景预先定义 `gold_next_action`，把最终调查决策转化为可检验答案：

- 空结果恢复：改写查询或调整筛选；
- 来源冲突：先做实体/来源核验；
- 竞争性假设：执行替代解释检索；
- 证据充分：停止继续检索；
- 截点泄漏：隔离未来材料并停止；
- 补查缺口：创建带依据和验收条件的补查任务。

`decision_correctness` 是首个有效决策是否属于该场景的预注册正确动作集合。它比安全通过率更接近用户真正关心的“下一步是否做对”。

## 当前 24 条 V4 对照

| 方法 | 决策正确率 | 决策价值 | 安全约束通过率 |
|---|---:|---:|---:|
| 固定流程 | 16.7% | 51.67 | 100% |
| 普通 RAG | 50.0% | 64.17 | 100% |
| 确定性工具循环 | 16.7% | 34.17 | 100% |
| Qwen 主动 Agent | **66.7%** | 61.67 | 100% |

Qwen Agent 的主要优势体现在状态条件动作正确率，而不是安全通过率。普通 RAG 在一次反证检索任务上可能取得较高分，但不具备停止、冲突核验和补查时序能力。固定流程的安全通过率高只是因为它们共享确定性工具和截点验证器。

## 仍需补充的真实答案指标

V4 的动态决策正确率衡量“下一步是否做对”。对于最终调查结论，还需要为 EA22002、PE20016、PE23015 和 PE24004 分别建立 holdout 结案答案，包括：最终缺陷/非缺陷判断、召回或处置结果、主要支持证据和关键反证。只有这些答案从运行索引中完全隔离后，才能计算最终结论命中率、证据支持率和反证发现率。
