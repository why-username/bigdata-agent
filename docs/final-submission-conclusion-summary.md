# 无 Qwen API 条件下的最终收口方案

## 当前实验版本和计划位置

项目当前实现是 **V4 Agent 体系**：动态状态、竞争性假设、反证优先、证据图、有限重规划、截点安全门、状态快照和可审计轨迹都已接入。研究计划的阶段 1–4 已完成，阶段 5 的测试与验收已有完整离线套件和多轮真实 Qwen 试验，当前进入阶段 6：冻结结论、整理运行报告、PPT、Demo 和代码说明。

没有 Qwen API 后，后续本地运行只能验证工程闭环，不能新增真实模型调查质量结论。离线规则策略可以继续用于复现、回归测试和 Demo，但必须在报告中明确标注为工程验证。

## 最可靠的证据层次

### 主结果：88 条真实 Qwen API 研究任务

文件：`outputs/evaluations/eval-research_api-88-optimized.json`，对应报告：`docs/qwen-expanded-api-88-optimization-report.md`。

11 个公开案例、每案最新历史截点、8 个调查目标，四种策略使用同一快照和截点，并发为 1。

| 方法 | 自动流程分（5分） | 解释 |
|---|---:|---|
| 固定流程 | 3.125 | 稳定、可复现的流程基线 |
| 普通 RAG | 2.125 | 只做一次证据检索，缺少状态更新 |
| ReAct/确定性工具循环 | 3.250 | 规则化工具循环消融基线 |
| Qwen 主动调查 Agent | 3.193 | 有计划、状态、验证和有限重规划 |

Qwen Agent 88/88 条通过结构性自动验收，79 条完成，9 条进入人工复核；平均延迟约50.33秒，平均 token 约24,830。Agent 明显高于普通 RAG，和固定流程接近，略低于本实验中的确定性 ReAct 基线。因此主结果不能写成“Agent 全面优于基线”，应写成“Agent 在流程覆盖和可审计调查闭环上优于单次 RAG，但尚未证明在语义调查质量上优于固定或 ReAct 基线”。

### 动态行为补充：V3/V4 API pilot

V3 使用 4 个迁移案例、6 类动态场景，共24条 Qwen API 任务；V4 在同一任务上加入四方法统一结构和显式安全门。V3 的24条任务中23条通过截点与引用检查，1条达到最大轮数；来源冲突、反证重复检索和补查时序仍是弱点。V4 API pilot 的24条任务完成结构性验收，但来源冲突仍可能沿用默认搜索，反证场景仍有相似查询重复。

V4 的原始统一表给出 Agent 首步动作正确率 66.7%，固定流程 16.7%、普通 RAG 50.0%、确定性循环 16.7%。这个数字必须拆开解释：其中“证据充分停止”和“截点泄漏停止”由 V4 安全门强制纠偏，属于系统安全能力，不是模型自主动作；“补查缺口”也记录了安全门干预。因此真正可归因于模型自主选择的未干预场景只有空结果恢复、来源冲突和竞争性假设三类，4个案例均按预注册动作完成，但场景数仍只有3类，不能作为普遍动态能力的统计证明。

V3/V4 的可靠结论是：动态任务和失败模式已经被真实 API 复现，系统能测出模型何时沿用默认搜索、重复反证检索或需要安全门纠偏。它们不能证明 Agent 已稳定优于所有基线，也不能把100%的安全通过率解释成100%的调查正确率。

### 工程验证：264 条离线研究基准

文件：`outputs/evaluations/eval-research-20261101-000348.json`。

264/264 条任务完成，固定流程、普通 RAG、ReAct 和 Active-EIG 都能保存状态、轨迹、证据图并通过确定性边界检查。主动策略与 ReAct 的规则行为分相同，因此该套件证明工程可复现性和安全边界，不证明模型语义能力提升。

### 探索性附录：结案后不完整反馈

文件：`outputs/evaluations/key-incomplete-feedback-calibrated.json`。

4个案例的校正分数为固定流程/RAG/ReAct 0.500，Agent 0.875。该结果只能作为探索性现象，因为样本很小，基线没有生成与 Agent 完全同构的调查报告，而且评分包含规则化组件。原始 0%/100% 结果已明确废弃，不进入主结论。

## 最终可以安全写出的项目结论

本项目构建了一个面向公开车辆安全调查资料的企业工程原型。Agent 能在固定时间截点和本地证据快照上完成计划、工具调用、证据登记、竞争性假设、反证检索、补查任务、状态持久化、来源核验、有限重规划和安全停止，并生成可回放的调查轨迹。

真实 Qwen 试验显示，主动 Agent 相比普通 RAG 具有更完整的调查过程和更强的任务覆盖；相比固定流程的收益较小，相比当前确定性 ReAct 消融基线没有稳定优势。Agent 的核心价值应定位为早期筛查、证据缺口识别、升级/补查决策和不确定性控制，而不是自动替代车企最终的安全缺陷认定。

在公开资料和历史回放条件下，系统不能证明真实企业处置周期缩短，也不能把投诉数量当作故障率，更不能在结案前宣称已经确认车辆存在某一安全缺陷。所有事实性主张都必须回到本地来源快照、发布日期、SHA-256 和工具结果。
