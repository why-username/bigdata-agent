# 关键实验：不完整结案反馈下的四方法对照

上一轮“完整结案反馈”实验产生了结果天花板，因此不作为 Agent 优势证据。本实验只提供阶段 B 的不完整官方反馈：确认存在安全相关条件，但不披露最终机制和召回编号；最终答案仅用于评分，不进入提示词或检索材料。

原始运行文件：[key-incomplete-feedback-comparison.json](../outputs/evaluations/key-incomplete-feedback-comparison.json)。其中的 0%/100% 汇总存在评分器偏置，已降级为运行轨迹。校正后的结果见：[key-incomplete-feedback-calibrated.json](../outputs/evaluations/key-incomplete-feedback-calibrated.json)。

| 方法 | 校正后综合分 | 证据利用率 | 引用有效率 | 不过度断言 |
|---|---:|---:|---:|---:|
| 固定流程 | 0.500 | 100% | 100% | 100% |
| 普通 RAG | 0.500 | 100% | 100% | 100% |
| 确定性工具循环 | 0.500 | 100% | 100% | 100% |
| 主动调查 Agent | 0.875 | 100% | 100% | 100% |

前三种方法都能检索到新增材料并通过引用与安全检查，但没有形成“更新当前判断、保留机制不确定性、提出证据缺口”的结果层输出。主动调查 Agent 在 3/4 个案例中完成了这些额外组件，并且没有把未披露机制写成已确认事实。综合分采用六个组件，避免把结果压缩为 0%/100%。

这才是本项目需要展示的 Agent 价值：不是在答案已经给出的情况下复述答案，而是在反馈不完整时将新证据纳入状态、更新竞争性假设、保留未决问题并继续规划核查。该实验仍是课程原型，下一步可加入冲突反馈和错误来源条件，检验 Agent 是否能拒绝错误更新。
