# 车辆缺陷主动调查决策 Agent：研究级期末项目方案

## 项目重新定位

项目从“调用五个工具的课程原型”升级为一个可复现实验系统：研究 Agent 是否能在车辆安全投诉调查中，根据当前证据和不确定性主动选择下一项核查，并在有限预算下提高证据覆盖、反证发现和引用可核验性。

研究对象是公开资料历史回放。系统不访问车企内部质量系统，不派发真实任务，不自动判断车辆存在安全缺陷。在线 Demo 展示的是调查辅助过程、证据链和待确认任务。

## 可检验研究问题

**RQ1：** 在相同资料、同一截点和同一工具预算下，主动调查策略能否比固定流程和单次 RAG 找到更多“与当前假设相关且可核验”的证据？

**RQ2：** 加入反证优先和证据图后，Agent 是否能减少只收集支持材料的确认偏差？

**RQ3：** 证据截点、来源冲突和工具失败出现时，带验证器和有限重规划的 Agent 是否更少产生越界引用、无来源断言和无限重复调用？

**RQ4：** 主动调查的收益是否值得额外模型调用、token 和延迟成本？

## 研究方法创新

1. **证据图（Evidence Graph）**：节点包括投诉、车型、年款、部件、症状、调查、召回、来源文件和时间点；边保存匹配依据、来源、日期和置信状态。文本相似只形成候选边，不直接合并根因。
2. **主动证据策略（Active Evidence Policy）**：每个候选动作估算 `utility = expected_information_gain × source_reliability − retrieval_cost − duplication_penalty`，优先选择能区分竞争性假设的工具调用。
3. **反证优先计划**：每个支持假设必须生成至少一个替代解释和反证查询；证据分类为支持、反对、中性、待确认，分类必须绑定来源或确定性工具结果。
4. **可审计 Agent 轨迹**：计划、动作、观察、验证、重规划、停止原因、证据来源和模型成本全部保存为 JSON/JSONL，可逐步回放。
5. **自动化行为评测**：预注册任务目标和期望工具，自动检查证据覆盖、引用、反证动作、补查动作、截点边界、重复调用和停止行为，减少人工语义评分依赖。

## 数据规模与案例设计

主案继续使用 EA23003，因为它有 1,949 条本地投诉、528 条截点前 `STEERING` 记录、PE23005→EA23003 调查链和可留出的结案摘要。主案不宣称投诉数等于故障率，也不把同一投诉集合拆成多个独立证据来源。

研究级数据包应继续扩展到：

- NHTSA FLAT_INV 中筛出的 51 个有结案日期调查候选；
- 至少 8 个具有明确部件、投诉记录和公开结案材料的迁移案例；
- 每案 2–3 个历史截点，严格隔离截点后材料；
- 投诉原始记录、调查/召回文件、来源快照、来源日期、SHA-256 和数据质量报告；
- 通过规则生成的异常样本：缺日期、来源冲突、重复投诉、未来材料、空检索和工具错误。

主案用于完整调查链；迁移案例用于跨部件泛化；异常样本用于安全边界。替代主案必须满足：截点前至少两类独立公开材料、可关联投诉、可留出后续答案、可以定义支持与反证任务。单纯投诉量更大不构成替换理由。

## 对照实验

每个任务冻结案例、资料截点、目标、候选工具和预算，运行四种策略：

1. 固定流程：筛选→趋势→证据→关联；
2. 普通 RAG：一次检索后回答；
3. ReAct Agent：工具调用和观察交错，但不做信息增益规划；
4. Active-EIG Agent：证据图、竞争性假设、反证优先和成本约束全部打开。

至少完成 264 个离线任务（11 个案例 × 8 个调查目标 × 3 个截点），再从每案最新截点选择代表任务跑 Qwen API。每次 API 运行并发为 1，固定模型、温度、最大 token 和总调用预算。

自动指标：

- 证据文档覆盖率和去重原始投诉覆盖率；
- 独立来源族数量；
- 支持/反对/中性/待确认证据平衡度；
- 反证查询命中率；
- 竞争性假设区分率；
- 引用可核验率；
- 截点泄漏率、无来源断言率、重复调用率；
- 补查任务的依据完整度、验收条件完整度和反馈后续跑率；
- 工具调用数、延迟、prompt/completion/total token、模型成本。

自动分数只衡量可审计行为，不把“调用更多工具”当作质量。主结果报告均值、标准差、95% bootstrap 置信区间，并按案例和截点分层。

## 技术架构

Python + Streamlit，分为数据层、证据图层、工具层、策略层、验证器、状态/记忆层和报告层。Qwen 通过 OpenAI-compatible API 接入；离线规则策略保留为可重复工程基线。新增的主动策略可先使用规则化信息增益，随后再让模型选择候选动作，避免把研究结论完全归因于模型偶然输出。

## 当前实现进度

研究级基准生成器已实现：`scripts/build_research_benchmark.py` 从 11 个公开快照生成 264 条任务（11 案例 × 8 目标 × 3 截点）。证据图和规则化 Active-EIG 策略已接入 `agent/evidence_graph.py` 与 `agent/core.py`，每次运行会保存图、候选动作 utility 和选择轨迹。评测器已增加 ReAct 对照、均值/标准差和固定种子的 bootstrap 95% 区间。

首轮离线运行结果保存于 `docs/research-benchmark-results.md`。264 条研究任务和 24 条快速回归任务均可一条命令运行；`research_api` 会固定抽取每案最新截点的代表任务，需在共享服务器负载允许时执行，不能用离线结果替代真实模型质量结论。

扩展数据 API pilot 已完成 22 条跨案例任务，结果见 `docs/qwen-expanded-api-pilot-report.md`；完整最新截点 API 套件当前为 88 条任务。
