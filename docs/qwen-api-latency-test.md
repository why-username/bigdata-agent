# Qwen API 单步推理测量

测试时间：2026-10-31（本地通过 SSH 隧道访问实验室服务器）

- 服务：`http://10.214.107.90:30000/v1`
- 模型：`/model`
- 请求：单步 JSON 工具决策
- `max_tokens=256`
- `enable_thinking=false`
- 并发：1

## 结果

1. 初始空状态/短上下文：HTTP 200，约 **3.52 秒**，456 token。
2. 第一轮 `search_records` 返回后的压缩上下文：HTTP 200，约 **22.14 秒**，输入约 5,279 token，输出达到 256 token 上限。

第二次请求虽然在 90 秒内返回，但模型输出因达到 token 上限而截断，并额外生成了未声明的 `record_ids` 参数，不能直接视为有效 Agent 动作。此前超过 90 秒的现象主要来自更大的上下文和服务器当时负载；本次单步长等待测试没有继续扩大到完整评测。

结论：API 可用；短上下文延迟约 3–4 秒，带首轮记录摘要的下一步决策约 22 秒。完整 15 条 API 评测应先增加动作输出约束、拒绝未声明参数，并设置总调用预算，不能直接按离线评测规模压测公共服务。
