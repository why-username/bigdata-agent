# V3 动态决策离线验证

V3 候选包包含 EA22002、PE20016、PE23015、PE24004 四个案例，共 581 条截点前投诉和 8 条调查/召回证据。离线动态套件运行 24 条任务（4 案例 × 6 场景），所有任务通过来源与截点检查。

六类场景的规则 Active-EIG 策略首步分支正确率均为 1.0：空结果恢复、来源冲突、竞争性假设、证据充分停止、截点泄漏和补查缺口。结果文件为 `outputs/evaluations/eval-research_v3-dynamic-offline.json`。

这一步验证的是 V3 评测结构、状态字段、分支动作和安全停止逻辑，不代表 Qwen API 已经达到同样的动态决策质量。下一步需要把相同的 `dynamic_scenario` 初始状态注入 Qwen API pilot，并与固定流程、普通 RAG 和确定性工具循环比较。
