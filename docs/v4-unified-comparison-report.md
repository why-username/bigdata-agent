# V4 四种方案统一指标对比

V4 在 4 个动态候选案例、6 个动态场景、24 条相同任务上建立了统一对照。四种方法使用相同案例、截点和任务目标：固定流程、普通 RAG、确定性工具循环和 Qwen 主动调查 Agent。

## 当前结果

| 方法 | 首步动作正确率 | 四维决策价值 | 最终安全通过率 |
|---|---:|---:|---:|
| 固定流程 | 16.7% | 51.67 | 100% |
| 普通 RAG | 50.0% | 64.17 | 100% |
| 确定性工具循环 | 16.7% | 34.17 | 100% |
| Qwen 主动 Agent | 66.7% | 61.67 | 100% |

四维决策价值由安全与可追溯性 30%、目标覆盖 25%、证据质量 20%、下一步价值 25% 组成。工具调用数不进入质量分。

## 结果解释

Qwen Agent 的首步动态动作正确率最高，说明在状态分支任务中，它比固定顺序方法更能选择场景相关动作。它在补查、反证、来源冲突等任务中表现出动态选择。

普通 RAG 的总分较高，主要来自一次证据检索在证据质量上的收益。它没有多步状态决策能力，因此不能处理证据充分停止、冲突核验和补查时序等复杂分支。

固定流程和确定性工具循环的首步动作正确率较低，是因为它们不读取 V4 的动态场景标签，始终按默认顺序执行。它们的优势是稳定和可复现，适合作为流程基线和消融基线。

## 指标限制

当前固定流程、普通 RAG 和确定性工具循环的决策价值是由可观察工具结果计算的代理分数，尚未像 Qwen Agent 一样记录完整的动态状态和安全门轨迹。因此，这张表适合做阶段性对比，不能作为最终论文级结论。

下一步需要让四种方法都显式接收同一 `dynamic_state`，并为固定流程、普通 RAG 和工具循环记录同样的状态、停止理由和证据缺口。完成后再计算最终对照结果。
