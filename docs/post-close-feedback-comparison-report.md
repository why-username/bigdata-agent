# 结案后反馈再运行与四方法结果层对照

## 实验目的

本实验把四个迁移案例的结案后公开反馈作为阶段 B 的新增输入，检验系统能否在新证据到达后更新调查结论。阶段 A 使用结案前快照，阶段 B 使用单独的 post-feedback 快照；两阶段不共用运行目录，避免结案材料泄漏到回放阶段。

案例为 EA22002、PE20016、PE23015 和 PE24004。每案的阶段 B 截点为新增官方材料的公开日期。新增材料保存来源 URL、公开日期、引用定位和 SHA-256。机器可读结果见 [`post-close-four-method-comparison.json`](../outputs/evaluations/post-close-four-method-comparison.json)。

## 指标定义

- **决策正确率**：方向、主要机制和处置三项均与留出的结案答案一致。
- **结论更新率**：阶段 B 运行实际纳入新增结案证据并改变阶段 A 的 provisional assessment。
- **过度自信率**：没有新增官方证据时却声称已经确认最终缺陷，或把推断写成已证实事实的比例。
- **证据利用率**：阶段 B 检索到新增材料，并把它用于结论/报告。
- **引用可核验率**与**安全通过率**：独立检查来源、日期、引用定位和截点边界；它们不是决策正确率的替代指标。

## 结果

| 方法 | 决策正确率 | 结论更新率 | 过度自信率 | 证据利用率 | 引用可核验率 | 安全通过率 |
|---|---:|---:|---:|---:|---:|---:|
| 固定流程 | 100% | 100% | 0% | 100% | 100% | 100% |
| 普通 RAG | 100% | 100% | 0% | 100% | 100% | 100% |
| 确定性工具循环 | 100% | 100% | 0% | 100% | 100% | 100% |
| 主动调查 Agent | 100% | 100% | 0% | 100% | 100% | 100% |

四种方法在阶段 B 达到相同结果，是因为实验有意把同一份明确的官方结案反馈提供给所有方法；这验证的是“结案后反馈能否被安全吸收”的闭环，而不是 Agent 在信息不完整时的优势。该结果不能支持 Agent 已经优于基线，也不能把安全通过率解释成真实缺陷判断正确率。

Agent 的可区分价值仍应在阶段 A 和反馈到达前的动态任务中观察：它需要在证据不完整时管理竞争性假设、寻找反证、提出可执行补查、决定何时停止，并在阶段 B 对原判断进行可追溯更新。当前阶段性结果显示，Agent 的优势假设是“主动调查与不确定性控制”，而不是在答案已经被直接告知后获得更高的终局命中率。

## 阶段性结论与限制

这次实验完成了四案结案后反馈闭环、统一输入下的四方法结果层对照和四项指标落盘。下一轮应增加“反馈不完整/反馈冲突/仅提供部分结案证据”的阶段 B 条件，并保持留出答案不直接注入提示词；这样才能测量 Agent 是否比固定流程、普通 RAG 和确定性循环更能利用新证据、修正错误假设并避免过度自信。生产部署仍需企业质量系统、权限、审计、模型降级和人工签核验证。
