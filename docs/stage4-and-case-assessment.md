# 阶段四实现与主案适用性评估

## 核心结论
保留 EA23003 为主案。528 条截点前转向投诉足够验证筛选、趋势、去重候选、来源追踪及工具闭环，但目前两条索引文档来自同一投诉集合，不能视为两个独立证据来源，也不足以验证主动反证调查的增益。

历史边界：官方调查全量数据记录 EA23003 开案日为 2023-11-29，结案日为 2025-01-28；前置 PE23005 开案于 2023-03-17，结案于 2023-11-30。2023-11-28 截点属于 EA 开案前回放。全量表当前摘要是后续结案摘要，不得因为包含早期开案日期而导入为截点前证据。

## 数据充分性
- 本地 EA23003 共 1,949 条投诉，截点前全组件 682 条，其中原始组件含 STEERING 的 528 条。
- 两条汇总/样本索引相互重叠，独立来源族只有投诉数据；提高文档数不等于增加独立证据。
- 2026 年保存的 API 内容按投诉接收日回放，不是 2023 年档案网页快照；接收日不能严格证明当前完整文本在当日已公开，报告需标注回溯重建限制。
- 当前采集的车型/年款范围是研究样本，不能宣称全部 ODI 案件投诉总数；不能用投诉数估计故障率或试验统计功效。
- 推荐比较单元：不同车型、时间窗口、症状/维修条件任务；在同一原始投诉集合上冻结查询与相关性标签，分开计量记录检索、独立来源族和人工建议质量。

## 替代案例筛选
本轮新增 NHTSA FLAT_INV 官方全量调查快照，保存来源、HTTP 状态、SHA-256 和保存日期。对 Honda/Ford/Tesla/Chevrolet/Hyundai 的 2020–2023 年款、2019 年后开案且有结案日期的调查去重，得到 51 个调查候选，完整列表见 data/processed/odi_case_candidates.json。

优先复核：
- EA23002 / PE21020：Tesla Autopilot，具备前置调查和工程分析链，适合反证与边界分析；投诉与自动驾驶启用状态不易可靠关联，尚未满足直接替换条件。
- PE22002：Tesla unexpected braking，症状竞争解释适合比较；不能把现有制动卡钳召回投诉直接当作该案投诉，需重新关联与冻结。
- PE23013：Ford Escape 车门连接点，和已有发动机召回不同，故障对象更具体；需单独收集车门投诉及截点前文件。
- PE21010：Chevrolet Silverado 气囊，和已有制动召回不同；尚需核实截点前投诉与材料数量。
- PE23011：Hyundai Ioniq 5 动力丧失，存在明确结案记录；需补齐车型投诉、技术通报与后续答案隔离。

已有 22 个车型筛查中，Explorer 发动机召回截点前仅16条、Escape 发动机召回21条、Silverado制动10条；Tesla制动案仅3条（该数字按现有导入日期规范化计算，原始日期格式需统一后比较）。这些数据并未显示优于 EA23003。召回 API 当前 Remedy 含后续通知内容，不可用 ReportReceivedDate 代替整段文本公开日期。

## 当前选择与下一步数据门槛
不以投诉总量最大作为替换理由。替代主案必须同时拥有：可明确关联的投诉样本、截点前至少两类独立公开材料、可隔离的后续结案答案、可定义支持与反证任务。当前已找到更值得深入验证的候选，但未证明任何一个已全面优于 EA23003。优先沿 PE23005→EA23003 补材料，其次验证 PE23013 或 PE23011。

## 阶段四边界
新增受控动作校验、验证失败的恢复任务、无信息重复动作停止、总轮数上限、续跑案例/截点绑定、去重失败记忆和按案例检索、立场枚举/依据要求、竞争性假设和工具结果观察。离线模式用于验证闭环；未运行真实模型的调查质量试验。工具验证只能确认来源结构和时间边界，不能自动证明源内容或因果断言为真。
