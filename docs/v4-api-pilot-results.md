# V4 对照实验与 Qwen Pilot

V4 修复了 V3 未运行其他方法的缺口。离线对照套件包含 24 条任务，记录固定流程、普通 RAG、确定性工具循环和主动 Agent。Qwen API pilot 在同一批 24 条任务上完成，案例、截点和目标一致。

V4 的 Qwen 结果：24/24 任务完成处理并通过结构性自动验收。场景首步动作正确率和平均决策价值已保存于 `outputs/evaluations/eval-v4-api-pilot.json`。模型在补查缺口、竞争性假设和部分充分证据/截点泄漏任务中能表现出动态选择；来源冲突仍有默认搜索倾向，反证场景存在相似查询重复。

V4 主要改进是把场景规则写进 Agent 上下文：来源冲突优先实体核验，充分证据和截点泄漏优先安全停止，补查缺口优先创建任务，反证查询后必须转向或停止。该 pilot 证明同一动态任务可以同时比较四种策略，下一步应把离线对照的固定流程、普通 RAG、工具循环首步动作和 Qwen 首步动作按场景汇总，形成主实验表。

针对低分场景，V4.1 增加显式安全门：证据充分和截点泄漏首步停止，补查缺口首步创建补查任务。安全门触发会记录 `decision_guards`，并标记 `autonomous=false`，因此不会被误报为模型自主能力。下一轮结果须分别报告模型首步正确率、安全门纠偏率和最终安全通过率。
