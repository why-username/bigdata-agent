# Agent V2 全量实验结果与迭代结论

## 运行完成情况

V2 使用与 V1 相同的 88 条最新截点任务、案例快照、并发 1 和 Qwen API。结果保存于 `outputs/evaluations/eval-research_api-88-v2.json`，过程文件为 `outputs/evaluations/api-research-88-v2-progress.json`。

- 88/88 条任务完成处理，自动验收通过率 88/88。
- 76 条 `completed`，12 条 `needs_human_review`。
- V2 旧版五分轨迹均值为 3.136/5；该指标不再作为主指标。
- 按四维决策价值评分（安全 30%、目标覆盖 25%、证据质量 20%、下一步价值 25%）重新计算，V2 用户决策价值均值为 **87.50/100**；同一批任务的 ReAct 为 **87.78/100**。
- V2 目标覆盖 0.955，下一步价值 0.909，安全与可追溯性 1.0，证据质量 0.545。
- ReAct 目标覆盖 1.0，下一步价值 0.875，安全与可追溯性 1.0，证据质量 0.545。
- 工具调用数、延迟和 token 作为成本诊断单独报告，不进入质量分。
- 平均延迟约 49.83 秒，平均 token 约 22,824。

## 与 V1 比较

V1 的 Agent 自动轨迹分数为 3.193/5，V2 为 3.136/5。这个下降不能直接解释为能力下降：V2 增加了目标完成门槛和重复调用安全停止，因此更多任务被标记为 `needs_human_review`，同时避免了为了得到完整工具链而继续产生低价值调用。V2 的主指标是用户决策价值，而不是旧的工具覆盖分数。

V2 的用户价值分数与 ReAct 基本相当，ReAct 总分略高 0.28 分。V2 在下一步价值上高于 ReAct，说明主动策略在反证和补查目标中更能提出面向缺口的动作；ReAct 在目标覆盖上略高，因为它按固定顺序执行全部工具。当前数据不支持宣称 V2 全面胜过 ReAct，但支持“主动策略改善了调查目标针对性”的结论。调用数和延迟只用于之后的成本收益分析。

## 失败与边界

V2 运行中出现 32 次无效 JSON、1 次非法动作类型、1 次重复调用安全停止和 1 次 HTTP 502。所有任务仍通过自动验收；协议错误被有界重试吸收，HTTP 错误没有导致删除或修改共享服务器文件。12 条 `needs_human_review` 应解释为计划未完全闭合或安全停止，不能直接当作数据失败。

## 研究结论

Agent 的核心价值不在于比固定流程调用更多工具，而在于根据调查目标选择下一步、主动查找替代解释、把无法取得的信息转为带依据和验收条件的补查任务，并在来源或截点不满足时停止。V2 已把这些行为纳入可复现的决策价值指标，但仍需要把模型动作格式约束和语义重复补查继续作为后续优化点。
